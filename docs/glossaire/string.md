Le mot anglais **string** est utilisé pour représenter le texte dans toutes les catégories du MDN. La traduction de ce mot est très relativement mélangée par des personnes et des outils qui ne prennent aucunement en compte les règles de différenciation, ce qui entraîne des incohérences et des incompréhensions. Nous utilisons donc **chaîne de caractères**, permettant de fournir le bon sens qui est attendu par les explications et ne pas créer un mélange avec **chain** qui lui est traduit par **chaîne**.

## Syntaxe

```markdown
string => chaîne de caractères
{{JSxRef("String")}} => chaîne de caractères ({{JSxRef("String")}})

<!-- La règle s'applique également pour : -->
substring => sous-chaîne de caractères
```
