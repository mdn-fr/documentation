L'anglais **Global object** correspond à la représentation d'un objet qui est interne à JavaScript. Nous les traduisons par **Objets natifs** et au singulier **Objet natif** en référence à l'ancien nom qui était <i lang="en">Built-in object</i>, par la suite renommé avec le mot «&nbsp;Global&nbsp;».
Cela permet de différencier les objets natifs de l'objet global lui-même qui est représenté par `this` dans la portée globale.

Il est encore possible de trouver l'ancien nom anglais dans les menus du MDN. C'est pourquoi nous préservons ce nommage en plus de sa capacité à donner un nom moins générique. Tel que cela est fait avec les [attributs universels de HTML](/docs/glossary/global_attribute).

## Syntaxe

```markdown
global object => objet natif
global objects => objets natifs
```
