Le mot anglais **return** est utilisé dans tout le MDN pour désigner la valeur de retour de quelque-chose. Qu'il s'agisse d'un élément HTML, d'une fonction JavaScript, d'une propriété ou méthode d'API, d'une réponse d'un serveur, ou de bien d'autres choses, le mot est traduit avec le verbe **retourner**.

Attention à ne pas utiliser le verbe **renvoyer** qui est un faux-ami réservé au mot anglais **resend** et ne concerne que des requêtes HTTP.

Il est utilisé dans le titrage des sections liées à JavaScript et ses API sous le nom «&nbsp;Valeur de retour&nbsp;». Ce nommage unique est imposé dans les pages par les règles d'écritures du MDN et définit donc la traduction implicite de son anglais.

## Syntaxe

```markdown title="Markdown"
<!-- Dans une phrase -->
return => retourne, retourner
returned => retourné, retournée

<!-- Dans une page décrivant une propriété, méthode, évènement de JavaScript -->
### Return value

devient

### Valeur de retour
```
