Le mot anglais **promise** correspond à l'objet natif JavaScript du même nom [`Promise`](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Global_Objects/Promise) et est traduit de façon littérale, car c'est la meilleure approche possible pour les promesses JavaScript.

## Syntaxe

```markdown
<!-- Dans une phrase -->
a promise => une promesse
promises => des/les promesses

<!-- Dans une phrase avec des accents graves autour pour l'afficher comme du code -->
a `Promise` => une promesse (`Promise`)

<!-- Dans une phrase sous la forme d'une macro de référence JavaScript -->
a {{JSxRef("Promise")}} => une promesse ({{JSxRef("Promise")}})

<!-- Dans une phrase sous la forme de lien -->
a [`Promise`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise) => une promesse ([`Promise`](https://developer.mozilla.org/fr/docs/Web/JavaScript/Reference/Global_Objects/Promise))
[a promise](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise) => [une promesse](https://developer.mozilla.org/fr/docs/Web/JavaScript/Reference/Global_Objects/Promise)
```
