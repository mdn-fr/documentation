Le mot anglais **reject** est utilisé dans le contexte des [Promesses](/docs/glossaire/promise) de JavaScript. Il signifie que la promesse a été **rompue**, donc qu'elle n'a pas atteint son point [d'aquittement](/docs/glossaire/settle) ou de [complétion](/docs/glossaire/fulfill).

De ce fait, nous utilisons le verbe **Rompre** pour traduire ce terme, mais lorsqu'il n'est pas possible de l'utiliser c'est au moment ou il n'est que possible d'écrire «&nbsp;**du/le rejet**&nbsp;».

## Syntaxe

```markdown
rejected => rompue
reject => rompt, rompre
```

```markdown
the reject value => la valeur de rejet
```

### Marquer l'anglais

Pour cette traduction, il est recommandé de marquer l'anglais au moins une fois dans la page. Par exemple&nbsp;:

```markdown
rompue (<i lang="en">rejected</i> en anglais)
```
