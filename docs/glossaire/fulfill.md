Le mot anglais **fulfill** est utilisé dans le contexte des [Promesses](/docs/glossaire/promise) de JavaScript. Il signifie que la promesse a été **complétée**, donc qu'elle a atteint son point de succès.

De ce fait, nous utilisons exclusivement le verbe **Compléter** pour traduire ce terme.

## Syntaxe

```markdown
fulfilled => complétée
fulfill => complète, compléter
```

### Marquer l'anglais

Pour cette traduction, il est recommandé de marquer l'anglais au moins une fois dans la page. Par exemple&nbsp;:

```markdown
complétée (<i lang="en">fulfilled</i> en anglais)
```
