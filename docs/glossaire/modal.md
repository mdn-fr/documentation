Le mot anglais **modal** désigne un élément créé par l'utilisation du HTML/CSS pour afficher des éléments de **fenêtres bloquantes** qui sont affichées au-dessus de toute l'interface. Ce qui bloque la possibilité d'interagir avec le reste du site tant que la fenêtre n'est pas fermée et que l'effet du pseudo-élément CSS `::backdrop` est actif.

## Syntaxe

```markdown title="Markdown"
<!-- Dans une phrase -->
modal => une/la fenêtre bloquante
modals => des/les fenêtres bloquantes
```

### Marquer l'anglais

Pour cette traduction, il est recommandé de marquer l'anglais au moins une fois dans la page car il existe 3 traductions pour des fenêtres différentes entre _Modal_, [Popover (contextuelle)](/docs/glossaire/popover) et [Popup (intrusive)](/docs/glossaire/popup). Par exemple&nbsp;:

```markdown title="Markdown"
fenêtre bloquante (<i lang="en">modal</i> en anglais)
```
