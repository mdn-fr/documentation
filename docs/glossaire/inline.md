Le mot anglais **inline** est utilisé dans différents contextes, il faut donc prendre des précautions sur la manière de le traduire.

Dans un contexte de paragraphe, de code en format de ligne continue ou imbriqué dans du balisage&nbsp;; la syntaxe appropriée est **incise**.

L'incise représente un élément qui fait partie d'une ligne complexe, mais qui n'a aucun rapport syntaxique avec le reste de la ligne. Par exemple une portion d'une phrase, ou du code écrit dans la ligne / imbriqué.

En revanche, lorsque le contexte concerne les lignes d'un tableau, d'une disposition de grille ou de boîtes flexibles, c'est bien la traduction **en ligne** qui prend le pas. Tant que le contexte n'entre pas dans le sens de la disposition qui lui est lié au contexte de la ligne (un axe en incise).

## Syntaxe

```markdown
inline box => boîte en incise
inline script => script en incise

the flexbox is defined inline => les boîtes flexibles sont définies en ligne
```
