Le mot anglais **popup** désigne un élément créé par l'utilisation du JavaScript pour afficher des éléments de **fenêtres intrusives** comme une console d'entrée avec `prompt()` ou `confirm()`. C'est ainsi qu'est traduit ce terme.

## Syntaxe

```markdown title="Markdown"
<!-- Dans une phrase -->
popup => une/la fenêtre intrusive
popups => des/les fenêtres intrusives
```

### Marquer l'anglais

Pour cette traduction, il est recommandé de marquer l'anglais au moins une fois dans la page car il existe 3 traductions pour des fenêtres différentes entre [Modal (bloquante)](/docs/glossaire/modal), [Popover (contextuelle)](/docs/glossaire/popover) et _Popup_. Par exemple&nbsp;:

```markdown title="Markdown"
fenêtre intrusive (<i lang="en">popup</i> en anglais)
```
