Le mot anglais **settle** est utilisé dans le contexte des [Promesses](/docs/glossaire/promise) de JavaScript. Il signifie que la promesse a été **acquittée**, donc qu'elle a atteint un point de succès mais qu'elle n'était qu'une promesse parmi un groupe de promesses. Cela est présent pour les [semi-promesses](/docs/glossaire/thenable) qui sont donc des chaînes de promesses faites avec `.then()`.

De ce fait, nous utilisons exclusivement le verbe **Acquitter** pour traduire ce terme.

## Syntaxe

```markdown
settled => acquittée
settle => acquitte, acquitter
```

### Marquer l'anglais

Pour cette traduction, il est recommandé de marquer l'anglais au moins une fois dans la page. Par exemple&nbsp;:

```markdown
acquittée (<i lang="en">settled</i> en anglais)
```
