Le mot anglais **popover** désigne un élément créé par l'utilisation du CSS pour afficher des éléments de **fenêtres contextuelles**. C'est ainsi qu'est traduit ce terme.

Cette fonctionnalité est très utiliser avec l'attribut HTML `popover` et les propriété CSS liées aux éléments d'ancrage et ancrés.

## Syntaxe

```markdown title="Markdown"
<!-- Dans une phrase -->
popover => une/la fenêtre contextuelle
popovers => des/les fenêtres contextuelles

<!-- Dans une phrase à plusieurs contextes -->
an infobox and a popover => une boîte d'information et une fenêtre contextuelle
```

```html title="HTML"
<div class="my-popover">My popover</div>

Est traduit :

<div class="ma-fenetre">Ma fenêtre contextuelle</div>
```

### Marquer l'anglais

Pour cette traduction, il est recommandé de marquer l'anglais au moins une fois dans la page car il existe 3 traductions pour des fenêtres différentes entre [Modal (bloquante)](/docs/glossaire/modal), _Popover_ et [Popup (intrusive)](/docs/glossaire/popup). Par exemple&nbsp;:

```markdown title="Markdown"
fenêtre contextuelle (<i lang="en">popover</i> en anglais)
```
