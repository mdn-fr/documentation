## Rétrospective

Le 9 septembre 2025, les mises à jour des pages ont connues un tournant dans la manière de fonctionner. Jusqu'à lors, les contributions étaient sporadiques et du côté de l'équipe nous faisions des modifications groupées qui prenaient du temps à arriver. Puis a été mis en place le système de **Cycle de thèmes**&nbsp;; qui permet entre autres de programmer une semaine sur un sujet, et ce sujet sera le seul sujet mis à jour par l'équipe avant de changer de sujet.

Ainsi, nous avions la possibilité de changer un nombre de pages conséquent dans une catégorie du site, pendant une courte période de sprint, avant de totalement changer de sujet pour ne pas nous fatiguer sur une seule section.

## Les prochaines étapes et les changements

Après cette période avec un système de cycle, il a finalement été noté qu'une semaine c'était trop court sur des sujets aussi larges que le JavaScript, certaines API, et plus tard pour des sujets plus poussés.

De ce fait, le cycle des nouvelles mises à jour de traduction et actualisation sera plutôt de 2 semaines. Et sera calé entre les mises à jour de Firefox qui sont maintenant de 1 toutes les deux semaines depuis le 1<sup>er</sup> septembre 2026.

Cela va permettre de traiter ou terminer les sujets suivants&nbsp;:

- Sujets ouverts
  - Guides CSS
  - En-têtes HTTP
  - Guides HTTP
  - Objets natifs JavaScript
- Prochains sujets
  - Guides SVG
  - Éléments SVG
  - Attributs SVG
  - Versions de Firefox de 44 à 142 (toutes celles qui manquent actuellement)
  - Guides JavaScript
  - Erreurs JavaScript
  - Opérateurs JavaScript
  - Instructions JavaScript
  - Expressions relationnelles (RegEx) JavaScript
  - Quelques API qui n'ont pas de pages traduites.
